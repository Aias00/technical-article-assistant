# 文种选择与加载

用户指定文种优先。没有指定时，从目的、受众和材料判断，在review.md注明判断；不要默认所有内容都是技术稿。

| 文种标识 | 识别线索 | 加载 |
|---|---|---|
| technical | 教程、API、系统架构、工程实践、性能实验 | types/technical.md |
| work-summary | 工作总结、项目复盘、阶段成果与下一步 | types/work-summary.md |
| promotion | 企业宣传、产品介绍、能力介绍、应用案例 | types/promotion.md |
| opinion | 行业观察、评论、观点论证、趋势分析 | types/opinion.md |

只加载本次相关文种。混合稿按章节适用：产品介绍里的API示例仍需技术核验，技术案例中的业绩数字仍需口径依据。用户更正分类后立即按新分类处理。
难以归类时先用通用核稿规则并注明假设，不为套模板改写用户目的。文学创作及法律、医疗等专业审查不在本轮专门支持范围；不能宣称具备相应专业审核能力。
文种影响核稿、证据和叙事结构，不等于视觉主题：公众号科技色仍为ai-tech，演示风格仍可选magazine/swiss。
