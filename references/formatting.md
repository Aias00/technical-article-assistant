# 排版与检查范围

- `ai-tech`：科技色，默认；`mist-blue`：蓝灰技术编辑风。
- 其他主题：forest、sunset、slate、midnight、tech-blue、warm-orange、forest-green、midnight-purple、business-gray、light-purple。
- Markdown是源文件；修改正文后重新生成HTML，避免长期手改派生文件。
- HTML仅包含文章正文，一级标题和YAML元数据不进入正文。平台标题需另行填写。
- 转换器不会上传本地图片；交付时核对路径，平台可用性需另行验证。
- HTML检查仅检查一级标题与部分标签数量，不是完整DOM或视觉验证。
- 封面检查仅验证文件及部分PNG尺寸信息；不证明内容质量、完整解码或平台最终可用性。
- 文风检查针对预置中文表达模式，不是事实核验、语法纠错或AI生成检测。

## 微信交付步骤

主题CSS中的支持规则会转换为元素的内联style；页面head样式仅用于本地预览。复杂选择器与微信不支持的CSS仍可能丢失，不能保证还原所有视觉细节。

1. 在浏览器打开生成HTML，复制渲染后的正文，不直接粘贴HTML源码。
2. 在公众号后台单独填写标题；上传本地图片并替换正文相应位置。相对路径、file://和本机绝对路径均不能保证在微信可用；外部图片也需核验访问性与授权。
3. 在公众号编辑器检查字体、列表、表格和代码块，再通过手机预览核对图片和窄屏布局。
4. 标明是否实际验证过粘贴及手机预览。脚本测试不能替代微信后台验证。

## 文风检查限制

文风检查默认advisory，只输出建议且不改原文；strict命中时返回非零，off不检查。忽略闭合YAML元数据、顶层反引号/波浪线代码围栏、缩进代码、匹配的行内代码、以`>`开头的引用行以及同一行闭合的中英文引号内容。懒延续引用、跨行引语和复杂嵌套Markdown仍可能误判，需宿主按上下文判断。命中不代表事实错误或AI生成；不能为避免提示删改原意。仅排版模式始终跳过文风检查。

完整处理还检查本地图片存在性和顶层代码围栏闭合；远端图片不联网验证。仅排版模式仍保留原文，即使图片缺失也可能生成HTML，交付时应提示补图。代码与性能的运行验证另见code-verification.md。
