# review.md 模板

按实际范围填写，不制造发现或核验证据。只有核稿模式需要此报告。

```markdown
# 核稿报告

## 总评
- 文种与目标读者：
- 发布结论：Ready / Needs revision / Blocked
- 核验范围与限制：
- 来源台账及代码验证记录（若有）：
- 排版及视觉检查：未执行 / 本地检查通过 / 已预览（注明环境）

## 问题清单
- [Critical / Major / Minor] 标题
  - 位置及原文片段：
  - 原因与影响：
  - 证据或待核实项：
  - 建议及处理状态：

## 修改摘要
说明实际修改；只核稿则写“未修改原文”。

## 剩余事项
记录未核实的主张、未执行的测试及发布前操作。
```

无问题时保留总评，说明在本次范围内未发现问题；不要虚构问题凑模板。仅排版模式不生成核稿报告，也不声称核稿完成。
