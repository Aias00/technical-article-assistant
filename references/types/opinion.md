# 行业观察与观点文章

## 核稿

区分已发生事实、来源观点、作者推断、预测和建议。关键论断检查论据、推理链、适用条件与反例；表达立场不等于已证明结论。
公开行业数据优先原始统计、研究报告和公告，记录发布日期、样本、范围及口径。当前数据不能证明历史状态，过时数据不能直接支持“最新趋势”。
个别访谈、社交热度和少数案例不能自动代表整个行业；相关关系不能写成因果。没有足够证据就缩小结论或标待核实，不捏造反方观点。
直接引语保留原意与归属，不为润色重写被引用者的话；评论与商业宣传边界要说明。
不强制增加代码、命令或实验；仅涉及具体技术判断的章节需要技术核验。

## 文章与PPT

建议叙事：核心观点 → 事实与论据 → 解释与推理 → 反方/替代解释 → 条件化结论与启示。
PPT保持“论点—证据—限制”的对应关系，不能把“可能”改成“必然”，也不能把小样本观察浓缩成行业定论。
