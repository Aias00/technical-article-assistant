# 企业宣传与产品介绍

## 核稿

检查受众、痛点、能力、使用条件、可证实案例与价值，区分产品能力、测试结果、客户反馈和企业主张。
“全部支持”“唯一”“零风险”“保证收益”等承诺需要相应证据及范围；没有依据时指出问题，不悄悄包装成可信结论。
案例、客户名称、Logo、引语、使用数字须有可使用的来源和授权。没有真实客户资料时不编造客户案例、推荐语或“某头部企业已应用”的暗示。
营销语气可保留，但不得改变事实、夸大因果或删除限制。没有性能测量时不写提升百分比，不把演示场景当商业落地。
无需为了增加“技术含量”而添加代码、实验或内部实现；涉及具体技术能力时再核对相应依据。

## 文章与PPT

建议叙事：受众痛点 → 提供的能力 → 场景和证据 → 使用条件/限制 → 可执行的下一步。
PPT突出价值和可证实案例，注明案例范围；使用有数据的图表，无数据时用流程/能力说明，不造KPI撑版面。
