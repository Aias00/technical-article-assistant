# 工作总结与项目复盘

## 核稿

核对目标、时间范围、责任主体、实际交付、问题和后续行动，区分“计划做”“正在做”“已完成”。
数据需说明指标定义、统计周期、比较基线和来源。完成率的分母、去重口径、同比/环比不能混用；个人贡献与团队成果不混为一谈。
优先使用用户提供的获准业务记录、验收结果、会议纪要和统计表。不能用网络资料替代内部成果证明，也不将内部数据上传外部搜索。
无工时或质量测量就写“尚未测量”，不推算提效比例；不编造业绩、负责人、截止日期或验收结果。缺信息标待补充，行动建议明确为建议，不写成已决定事项。
不要求命令、API或代码，除非该章节确实涉及技术论证。

## 文章与PPT

建议叙事：目标与范围 → 实际成果及证据 → 差距与问题 → 原因和经验 → 后续行动。
PPT突出阶段成果、口径明确的数据、关键问题和下一步；责任人/时间未知时留待明确，不替用户指定。
保留限定条件：试点成果不外推为全公司效果，阶段交付不等于最终验收。
